FLOWCHART STUDIO — блок-схемы по ГОСТ 19701-90 для C++, C# и Python
=====================================================================

ЧТО ЭТО
  Программа читает исходный код (C++, C# или Python) и рисует блок-схему
  по правилам методички: пуск-останов, процесс, ввод-вывод, ветвление (+ / -),
  циклы, switch, подпрограммы. Отдельная схема строится для главной
  программы и для каждого метода. Во вкладке «Команды» можно хранить код
  четырёх команд, писать замечания друг к другу и собирать всё в один файл.


1. ЧТО НУЖНО УСТАНОВИТЬ (один раз)
-----------------------------------
  1) Python 3.9 или новее: https://www.python.org/downloads/
     ВАЖНО при установке на Windows:
       - поставьте галочку "Add python.exe to PATH";
       - не снимайте галочку "tcl/tk and IDLE" (без неё не откроется окно).
  2) Pillow (нужен только для сохранения в PNG). Откройте cmd и выполните:
         python -m pip install pillow
     Если PNG не нужен, а достаточно SVG — этот шаг можно пропустить.


2. КАК ЗАПУСТИТЬ
-----------------
  Способ А (проще всего):
     Положите flowchart_studio.py и start_flowchart.bat в одну папку
     и запустите start_flowchart.bat двойным щелчком.

  Способ Б (через cmd):
         cd C:\путь\к\папке\с\программой
         python flowchart_studio.py
     Если команда python не находится, попробуйте:  py -3 flowchart_studio.py

  Способ В (без окна, одной командой):
         python flowchart_studio.py мой_код.cpp -o схема.png
         python flowchart_studio.py мой_код.cs  -o схема.svg
         python flowchart_studio.py мой_код.py  --check     (только проверка кода)
     Ключи:  -l cpp|csharp|python  — задать язык вручную (обычно он определяется сам)
             --yesno               — подписи ветвей «Да/Нет» вместо «+/-»


3. КАК РАБОТАТЬ В ОКНЕ
-----------------------
  Вкладка «Блок-схема»
     - слева вставьте код или нажмите «Открыть файл…»; «Пример ▾» — готовые примеры;
     - нажмите «▶ Построить» (или F5) — справа появится схема;
     - «−» / «+» — масштаб; «Ветвление» — подписи «+ / -» или «Да / Нет»;
     - «Экспорт PNG», «Экспорт SVG» — сохранить всё одной картинкой;
     - «Каждая схема отдельно…» — для каждого метода свой файл;
     - снизу список найденных недочётов кода (автоанализ).

  Вкладка «Команды и проверка»
     1) Выберите команду (1–4), вставьте или загрузите её код.
     2) Команда 1 проверяет код команды 2, 2 — команды 3, 3 — команды 4, 4 — команды 1.
     3) Заполните «Замечание»: от кого, о чьём коде, номер строки, вид, текст
        и нажмите «Добавить».
     4) «Автоанализ → в замечания» — программа сама добавит найденные недочёты.
     5) «Показать блок-схему» — открыть код выбранной команды на первой вкладке.
     6) «Схемы всех команд → папка…» — сохранить схемы всех команд сразу.

  Вкладка «Сборка в один файл»
     - «Обновить предпросмотр» — показать общий файл: коды всех команд,
       а замечания вставлены комментариями под нужными строками;
     - «Сохранить объединённый файл…» — записать его на диск;
     - «Сохранить проект (JSON)…» / «Открыть проект (JSON)…» — сохранить
       или продолжить работу (коды и замечания всех команд в одном файле).
     Из командной строки:  python flowchart_studio.py --merge project.json -o итог.txt


4. КАК ЧИТАТЬ СХЕМУ
--------------------
  - Овал — начало / конец; у метода в овале его имя и параметры.
  - Прямоугольник — действие (присваивание, вычисление).
  - Параллелограмм — «Ввод: …» и «Вывод: …».
  - Прямоугольник с двойными боковыми линиями — вызов вашего метода.
  - Ромб — условие: «+» (истина) вправо, «-» (ложь) вниз.
  - Шестиугольник — цикл for: «начальное значение, условие, шаг».
  - Маленький кружок — место слияния веток (после if / switch).
  - break и continue показаны линиями: continue — к началу следующего шага цикла,
    break — к выходу из цикла.
  - В блоках записан алгоритм, а не код: i++ -> i = i + 1, && -> И, % -> mod.


5. ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
---------------------------
  "python не является внутренней или внешней командой"
      Python не добавлен в PATH. Используйте  py -3 flowchart_studio.py
      или переустановите Python с галочкой "Add python.exe to PATH".

  "can't open file ... No such file or directory"
      Вы находитесь не в той папке. Перейдите командой cd в папку, где лежит
      flowchart_studio.py, или укажите полный путь к файлу.

  "Can't find a usable init.tcl" / окно не открывается
      Не установлен Tcl/Tk. Запустите установщик Python -> Modify ->
      включите "tcl/tk and IDLE". Если запускаете из PyCharm, а в .venv не работает —
      запустите системным Python (см. способ Б) или пересоздайте .venv.
      Пока окно не работает, доступен режим без окна (способ В).

  "Для PNG нужен Pillow"
      Выполните:  python -m pip install pillow   или сохраняйте в SVG
      (SVG открывается в браузере).
